# 주봉 차트 앱 개발 계획

> 확정 사항: 한국 주식 포함 / 업비트·코인베이스 프리미엄은 한 페인에 함께 표시 / Cloudflare Pages 배포 / 암호화폐 메인 차트는 바이낸스 USDT 기준

## 1. 요구사항 정리

| 항목 | 내용 |
|---|---|
| 대상 | 주식, 암호화폐 |
| 시간 단위 | **주봉만** (일/월봉 전환 없음) |
| 메인 차트 | 캔들 + 이동평균 50주 / 120주 / 200주 |
| 하단 보조지표 (공통) | 거래량, RSI(14) |
| 하단 보조지표 (암호화폐만) | 업비트 프리미엄(김프), 코인베이스 프리미엄 |
| 즐겨찾기 | 종목 검색 → 별표 등록 → 목록에서 탭하면 바로 차트 표시 |
| 형태 | 모바일 브라우저에서 사용, 앱스토어 등록 없음 |

## 2. 플랫폼: PWA(웹앱) 권장

| 방식 | 장점 | 단점 |
|---|---|---|
| **PWA (권장)** | 앱스토어 불필요, 아이폰 Safari에서 "홈 화면에 추가"하면 앱처럼 전체화면 실행, Mac/Xcode 불필요, 업데이트는 배포만 하면 즉시 반영 | 백그라운드 알림 등 네이티브 기능은 제한적 (이번 요구사항엔 불필요) |
| 네이티브 iOS (SwiftUI) | 네이티브 성능 | Mac + Xcode 필요, 무료 계정으로 설치 시 **7일마다 재설치** 필요, 유료 개발자 계정(연 $99) 필요 |

→ 요구사항상 네이티브 기능이 필요 없으므로 **PWA**로 진행.

## 3. 기술 스택

- **프론트엔드**: Vite + TypeScript + React
- **차트**: TradingView **Lightweight Charts v5** (오픈소스, Apache 2.0)
  - 캔들 / 라인 / 히스토그램 시리즈 지원, v5부터 **멀티 페인(pane)** 지원 → 메인·거래량·RSI·프리미엄을 한 차트에서 시간축 동기화
  - 모바일 터치(핀치 줌, 드래그) 지원
- **PWA**: vite-plugin-pwa (manifest, 서비스워커, 오프라인 캐시)
- **API 프록시**: Cloudflare Pages Functions (또는 Workers) — 무료 플랜으로 충분
  - 이유: Yahoo/업비트 등은 브라우저 직접 호출 시 **CORS 차단**, 캐싱으로 호출 수 절감
- **저장소**: 즐겨찾기 → localStorage, 시세 캐시 → Cloudflare 엣지 캐시 + 서비스워커(오프라인 시 마지막 데이터)
- **호스팅**: Cloudflare Pages (프론트 + 프록시 한 번에 배포)

## 4. 데이터 소스

### 주식
| 용도 | 소스 | 비고 |
|---|---|---|
| 주봉 OHLCV | Yahoo Finance chart API (`interval=1wk`, `range=max`) | 무료, 키 불필요, 미국(AAPL)·한국(005930.KS / .KQ) 모두 지원. 비공식 API라 변경 위험 있음 → 프록시에서 어댑터로 분리 |
| 종목 검색 | Yahoo Finance search API | |
| 대체안 | Twelve Data / Alpha Vantage (API 키 필요, 무료 호출 제한) | Yahoo 장애 시 교체 가능하도록 인터페이스화 |

### 암호화폐
| 용도 | 소스 | 비고 |
|---|---|---|
| 기준 주봉 OHLCV | Binance `klines?interval=1w` (USDT 마켓) | 미국 리전 IP 차단(451) 대비 `data-api.binance.vision` 미러 사용 |
| 업비트 시세 | Upbit `/v1/candles/days` (KRW 마켓) | 1회 200개 제한 → 페이지네이션 |
| 코인베이스 시세 | Coinbase Exchange `/products/{id}/candles` | **주봉 미제공(최대 일봉), 1회 300개** → 일봉 받아서 주봉으로 집계 |
| 원/달러 환율 | Yahoo `KRW=X` 주봉 | 김프 계산용 |
| 종목 목록 | Upbit `market/all` + Binance `exchangeInfo` | |

### 프리미엄 계산식 (주봉 종가 기준)
- **업비트 프리미엄(%)** = 업비트 KRW 종가 ÷ (바이낸스 USDT 종가 × USD/KRW 환율) − 1
- **코인베이스 프리미엄(%)** = 코인베이스 USD 종가 ÷ 바이낸스 USDT 종가 − 1
- 주봉 경계가 거래소마다 다를 수 있으므로(UTC vs KST), **모든 거래소를 일봉으로 받아 동일 기준(월요일 00:00 UTC)으로 주봉 재집계** 후 계산 → 시점 불일치 방지
- 업비트/코인베이스에 상장되지 않은 코인은 해당 프리미엄 페인을 "데이터 없음"으로 표시

## 5. 지표 계산 (클라이언트)
- **이동평균**: 종가 단순이동평균(SMA) 50 / 120 / 200주. 데이터가 기간보다 짧으면 해당 선은 미표시
  - 예: 200주선은 약 3.8년 이상 데이터 필요. 바이낸스 BTCUSDT는 2017-08부터라 200주선이 2021년 이후부터 그려짐
- **RSI(14)**: Wilder 방식, 30/70 기준선 표시
- **거래량**: 히스토그램, 양봉/음봉 색 구분

## 6. 화면 구성 (모바일 세로 기준)

```
┌────────────────────────┐
│ ☰  BTC/USDT   ★  ₩/$  │  ← 헤더: 종목명, 즐겨찾기 토글
├────────────────────────┤
│                        │
│  캔들 + MA50/120/200   │  ~45%
│                        │
├────────────────────────┤
│  거래량                │  ~13%
├────────────────────────┤
│  RSI(14)               │  ~13%
├────────────────────────┤
│  업비트·코인베이스     │  ~17%  (암호화폐만, 한 페인에 두 선.
│  프리미엄              │         코인베이스는 별도 눈금)
└────────────────────────┘
 [즐겨찾기] [검색]           ← 하단 탭바
```

- **즐겨찾기 탭**: 등록 종목 리스트(현재가, 주간 등락률), 탭 → 차트, 길게 눌러 순서 변경/삭제
- **검색 탭**: 주식/암호화폐 토글 + 검색창, 결과 옆 ★로 바로 등록
- 차트 십자선 터치 시 해당 주의 OHLC·MA·RSI·프리미엄 값 표시
- 다크 모드 기본

## 7. 개발 단계

| 단계 | 내용 | 산출물 |
|---|---|---|
| 0. 셋업 | Vite+React+TS 프로젝트, 린트, Cloudflare Pages 설정 | 빈 앱 배포 |
| 1. 데이터 계층 | 프록시 함수(Yahoo/Binance/Upbit/Coinbase/환율), 공통 `WeeklyCandle` 타입, 일봉→주봉 집계, IndexedDB 캐시 | API 엔드포인트 |
| 2. 차트 | Lightweight Charts 멀티 페인, 캔들+MA, 거래량, RSI | 주식/코인 기본 차트 |

한국 주식: Yahoo(`005930.KS`, `035720.KQ`)를 기본으로 쓰고 실패 시 네이버 금융 주봉으로 재시도. 한글 종목명 검색은 네이버 자동완성 사용.

| 3. 프리미엄 | 업비트·코인베이스 프리미엄 계산 및 페인 추가 | 암호화폐 전용 페인 |
| 4. 검색·즐겨찾기 | 종목 검색, 즐겨찾기 CRUD, 목록 화면 | 핵심 UX 완성 |
| 5. PWA | manifest, 아이콘, 서비스워커, iOS 홈 화면 대응(safe-area) | 홈 화면 설치 가능 |
| 6. 마무리 | 로딩/에러 처리, 단위 테스트(지표·프리미엄 계산), 실기기 확인 | v1.0 |

## 8. 리스크 / 유의사항
- Yahoo Finance는 비공식 API → 차단·스펙 변경 시 대체 소스로 교체 (어댑터 구조로 대비)
- Binance 미국 IP 차단 → 미러 도메인 또는 대체 거래소(OKX/Bybit) 사용
- USDT를 1 USD로 간주 (디페깅 시 프리미엄에 오차)
- 신규 상장 종목은 120/200주선이 그려지지 않음 (정상 동작)
- 개인용 도구로 사용하며 각 거래소 API 이용약관 범위 내에서 호출 (프록시 캐시로 호출 최소화)
